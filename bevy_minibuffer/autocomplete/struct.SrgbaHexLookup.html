Struct SrgbaHexLookup 

Source 
pub struct SrgbaHexLookup;
Expand description

This parses [Srgba] as hexadecimal color input in either three digits or six digits.

It does not provide completion as such. In a different language I might pull this out as something named Parse, but I don’t want to create yet another prompt_parse() if Lookup is sufficient for the job and it is.
